# Primora Publicador

Publica automaticamente no Instagram @primoradestaques os itens de `fila.json` (posts do feed e stories), de hora em hora via GitHub Actions.

A fila é montada no PC por `instagram-certificados/publicador/enfileirar.py`. A chave fica no secret `IG_ACCESS_TOKEN`.
